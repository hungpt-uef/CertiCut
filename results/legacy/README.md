# Superseded historical artifacts

Superseded result files are intentionally excluded from the current public working tree so that there is only one source of truth for manuscript reconstruction. Earlier versions remain recoverable from Git history.

The canonical representation-regret dataset is:

```text
results/e12_representation_placement_regret.json
```

The canonical derived summary is:

```text
results/e12_canonical_summary.json
```

The current release manifest is:

```text
results/final_manifest.json
```

Do not reconstruct current manuscript claims from historical commits without also consulting the protocol version current at that commit.
